# fs42-apps

![made with plain JS, HTML, CSS](https://img.shields.io/badge/made_with_-_plain_JS%2C_HTML%2C_CSS-yellow)
![GitHub License](https://img.shields.io/github/license/microTato/fs42-apps)

A collection of HTML files made by me for use with FieldStation42.

### Files included:
- news.html
  - A basic little RSS feed aggregator in HTML. Scrolls automatically.
- tmdb-movie-popular.html*
  - Channel that shows popular movies from TMDB.
- tmdb-tv-popular.html*
  - Channel that shows popular TV shows from TMDB. 
- tmdb-movie.html*
  - Older version of tmdb-movie-popular.html where users needed to specify what movies to showcase
- tmdb-tv.html*
  - Older version of tmdb-tv-popular.html where users needed to specify what TV shows to showcase
 
*A free TMDB API key is required
