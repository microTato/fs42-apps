## How to use

Move the contents of the iGuide folder to /path/to/FieldStation/fs42/fs42_server/static/customguide. Point a webchannel to http://localhost:4242/static/customguide/iguide.html?theme=iguide . You may add whatever you want on the end of the URL, just dont remove the theme parameter.

A image of your choice needs to be put in the custom guide directory named "logo.png" for the logo to appear.

The font "Roboto" needs to be installed in order for the guide to function properly. You can download it for free [here](https://fonts.google.com/specimen/Roboto).
